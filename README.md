# Perímetro Industrial

Prototipo FPS local construido con Three.js, modelos GLB y texturas CC0 aportados por el usuario.

```powershell
npm install
npm run dev
```

Controles: `WASD` para moverse, `Shift` para correr, ratón para mirar, clic izquierdo para disparar y `R` para recargar. El botón inferior derecho cambia entre calidad baja, media y alta.

Los modelos son de Quaternius / Toon Shooter Game Kit y las texturas de Poly Haven; ambos recursos se distribuyen bajo CC0. La distribución de la base toma como referencia el [City Kit (Industrial) de Kenney](https://kenney.nl/assets/city-kit-industrial), también CC0. El mapa Mirage (`public/assets/models/mirage.glb`, 22MB optimizado draco+webp desde 288MB) proviene de AXLEBOLT / CS2 Mirage vía [sandyards standoff 2](https://sketchfab.com/3d-models/sandyards-standoff-2-fbc824e0c4d3422796b67c7872e64621) por frostychaos144, CC BY 4.0.
